# L-E-COURS Roadmap

## v1.5 — Student Reading Workspace (current)
- In-app PDF reading for uploaded PDF resources using the browser PDF renderer.
- Breadcrumb navigation through the folder hierarchy.
- Recently opened files stored on the current device.
- Per-file personal study notes stored locally in the browser.
- Favourites and quick navigation to recent files.
- Responsive reader and note editor for desktop and mobile screens.

## v1.6 — Discovery and Operations
- PDF text extraction and full-text indexing.
- Advanced filters by academic year, file type, subject and resource category.
- Bulk upload and duplicate review workflow.
- Better sync reporting and removed-file reconciliation.
- PWA installability and carefully scoped offline caching.

## v1.7 — AI Study Tools
- AI assistant grounded in selected course documents with page references.
- Course summaries and QCM generation with source references.
- Flashcards and spaced-repetition study sessions.
- Usage controls, privacy safeguards and provider-cost limits.

## v1.8 — Student Workspace
- Optional student accounts for cross-device synchronization.
- Study planner, exam countdown and learning progress.
- Cloud-synced bookmarks and notes for signed-in users.

## v2.0 — Scale
- Public analytics and privacy-aware download metrics.
- Fine-grained admin roles and source permissions.
- React Native mobile client using the same API.
